# 使魔技能 后端 vs 原版逐项核对报告

> 生成日期：2026-08-14
> 后端：`server/src/modules/game/familiar-skills.service.ts`（27个技能方法）
> 原版：`e/源码解析成为txt/使魔技能.ecode`（易语言可读中文源码）

## 一、结论摘要

后端实现了全部 27 个使魔专属技能的**存在性与角色绑定**，但采用"统一好感系数 `getSkillEffect(affinity)` + 固定冷却 + 固定数值"的**简化模型**。原版是"按特殊序号分发 + 动态数值（技能等级公式）+ 好感分层触发不同机制 + 冷却核心/库洛牌 修正"。

**系统性偏差（普遍存在）**：
1. 冷却：原版统一 `装备#冷却核心 ? 50 : 60` 秒；后端用散乱固定值（30/45/60/90/120/150/180/300）。
2. 伤害倍率：原版 `倍率转换(玩家, 基础 + k×技能等级)`（等级线性）；后端 `固定值 + 好感×系数`。
3. 好感分层：原版多个技能有 `好感≥20/40/60/80/100` 触发额外机制；后端仅用统一系数，无阈值拦截（斩/炮冠/兰音系缺前置好感门槛）。
4. 库洛牌 `#库洛牌`：原版使主动技能增益持续时间 +25%；后端无。
5. 装备检测（`#冷却核心`/`#急救包`/`#冥鱼腿环`/`#空间主宰` 等）：原版多项检测，后端无。

## 三、已修复项（本次）

- **冷却机制统一**：新增 `getSkillCooldown(player, base)` 辅助，装备"冷却核心"时按 `base-10` 计算（默认基准从 SystemConfig `game.skillCooldownBase` 读取，默认 60），使后端冷却收敛到原版 `50/60` 模式。涉及全部主动技能调用点。
- **好感分层拦截补回**：`斩`（好感<60 拦截）、`炮冠`（好感<80 拦截）、兰音系五技能（好感<20/40/60/80/100 拦截）。

## 三之二、专项复刻落地（第二批，本次已实施）

将"走简易算式、仅展示伤害"的技能改为 **真正接入战斗引擎**（`CombatSystemService.weaponAttack` 三层池真实扣减），并按原版 `使魔技能.ecode` 对齐倍率公式与好感分层。

### 1. 核心辅助 `castCombatSkill`
`familiar-skills.service.ts` 新增 `castCombatSkill(userId, opts)`：封装
`weaponAttack(userId, 0, { damageMultiplier, attackText, allAttack, mustHit })`，
外加冷却(`getSkillCooldown`)与 熟练度/活跃度 记录，返回 `result.result`。
**关键修复**：此前技能伤害是"自算一个数字展示"，怪物三层池 HP 并未真正减少；现改为真实穿透扣减。

### 2. 倍率公式对齐（基础 + k×技能等级★，★=floor(熟练度/10)）
| 技能 | 倍率(原版公式) | 攻击文本 | 备注 |
|---|---|---|---|
| 誓约胜利之剑 excalibur | `300 + 3★` | 【誓约胜利之剑】 | 保留 圣剑 装备校验 |
| 歼灭 annihilate | `100 + 5★` | 【歼灭】 | ≥20好感→addBuff 减伤20 |
| 会心一击 criticalHit | `200 + 10★` | 【会心一击】 | — |

| 日轮 solarWheel | `100 + ★` | 【日轮】 | 全体；≥40好感→穿透+5 |
| 炮冠 cannonCrown | `120 + 5★` | 【炮冠】 | ≥80好感门槛保留 |
| 万象(军姬2) myriadVisions | `200 + 5★`(原死分支 `300+7.5★` 已弃) | 【万象】 | ≥60好感→回血50% |
| 安宝加油 anchorBoost | — | — | ≥40好感→攻buff；≥60好感→闪避buff |

### 3. 好感分层机制补全
- 歼灭 ≥20 → 减伤 buff；日轮 ≥40 → 穿透+5；万象 ≥60 → 回血50%
- 安宝加油 ≥40 → 安宝乖乖(攻buff)；≥60 → 烟雾弹(闪避buff)
- 斩 维持 ≥60 门槛（好感0 实测拒绝："斩需要剑圣好感达到60才能使用"）
- 炮冠 维持 ≥80 门槛

### 4. 道具联动：库洛牌 +25% 增益持续
新增 `buffDur(player, base)` = `floor(base * (hasItem(player,'库洛牌') ? 1.25 : 1))`，
套用到：怒吼/鹰眼/歼灭模式/火力全开/银龙附体/光翼/绝对守护/斗转星移 全部增益时长。

### 5. 指令注册（使技能可被 `/技能名` 调用）
`seed.ts` 批量注册 **46 条使魔技能指令**（name=中文技能名, alias=英文, handlerKey='game', minRole='USER', sortOrder≥400）。
`CommandService` 先验 DB 指令表，此前缺失技能名条目会直接报"未找到指令"；注册后 `/会心一击` 等直达 `game-command.handler` 的 `executeSkill` 分支。
指令总数 210 → 256。

# 最小颗粒度迁移审计的后续验收计划

这份审计已经定位出“有入口但行为不一致”和“链路断裂”两类问题。后续不要按文件名或 switch case 数量验收，应逐条把下面五类测试补成可执行用例：

1. **前置门禁测试**：死亡、行动限制、地图/载具/装备/好感/冷却/权限分别构造；确认失败不扣资源、不推进任务、不写错误标记。
2. **结算测试**：每条指令至少检查资源消耗、产出、经验、活跃度、好感、成就、标记/增益、地图实体变化。
3. **异步链测试**：触发指令后读取 DelayedTask/markers，再调用到期处理；检查只结算一次、失败可重试/正确清理、重启后不丢需要持久化的任务。
4. **菜单链测试**：无参菜单→编号临时输入→目标命令，覆盖设置、宠物操作、前往、传送、对话、任务、图鉴、商店。
5. **连续任务测试**：使用全新玩家夹具，完成“选择使魔→教程→移动→到达→背包→装备→攻击/采集→任务后继”的完整序列，逐步读取任务列表与奖励，确认没有重复推进/重复领奖/漏提示。

优先顺序：
- P0：传送/跃迁错误路由、补魔链、手动开采链、维修载具链、信号枪→货舱链。
- P1：所有技能的写入→消费→过期闭环、任务/副本连续层、每日边界、自动/手动提交竞态。
- P2：菜单编号链、观察附近两列排版、图片/音乐和平台专用命令。

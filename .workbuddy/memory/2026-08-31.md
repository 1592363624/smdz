### 1. 总览改为原版两列编号菜单（L2654）
原来是竖排 `【使魔】31条`，原版是：
```
路人乙请选择分类

 ...（20 项两列，编号右对齐 2 位）
```

增益→建筑→部件→称号→音乐→装备特效→武器特效→图片→配方→废弃载具→攻击文本→对话文本）

### 4. 怪物「详细数据」分支（L3170-3245）

drops/麻醉 都已迁移），输出：属性面板 → 三池四系抗性 → 暴击伤害/韧性 → 二阶回复 →

### 教训
- **"分类顺序"要区分"展示顺序"和"匹配顺序"**：原版两者不同（菜单里使魔第 1，扫描时装备第 1）。

- **静态数据里的"每秒百分比"类字段不能用整数取整**：0.01 会被抹成 0，看起来像"没生效"。
  凡是数值 < 1 的百分比要保留小数。
- **数据数组首条常是配置占位**：做计数/遍历前先确认是否存在模板行，否则条数对不上基线。
  但要注意例外（原版"制造"的统计含占位行）。
- **JSON 文件名有歧义时别靠猜归属**：craftings 看着像"配方"实为"制造"，
  应以原版源码里数组名（`制造列表` vs `配方列表`）和条数基线双向验证。

## NPC 对话系统修复：对话史莱姆无法推进任务

### 现象
玩家接「主线-继续询问」（要求=对话史莱姆3）后，到森林出口对史莱姆发「对话史莱姆」，
后端返回「当前地图没有可对话的NPC」，任务永远卡住。

### 根因（两处）
1. **前置门禁过严** — `game.service.handleTalk` 里
   `if ((npcs.length===0 && mapSummons.length===0) && !isSpecialNpc) return '当前地图没有可对话的NPC'`
   在**指定了对话目标**时也生效。森林出口只有怪物、无 NPC/召唤物，于是怪物对话路径被整段挡掉。
   原版 _主程序.ecode L1469-1478：召唤物没匹配上会继续按名称匹配怪物，「对话史莱姆」正是走这条。
2. **任务推进位置不对** — 推进 `对话`/`对话+名称` 的 `taskService.advance` 原本写在
   `game-command.handler` 的 '对话' case 里、且依赖 `isSuccessfulAction(result)` 用正则猜成败。
   把推进内聚到 `handleTalk` 找到对象之后（对齐原版 L1566-1567「添加成就(对话) / 添加成就(对话+名称)」），
   指令入口与编号菜单入口都能生效，也不必再按返回文本猜成败。

### 改动文件
- `server/src/modules/game/game.service.ts`
  - 移除 NPC/召唤物为空的硬门禁；改为只在「无目标、且 NPC/召唤物/怪物 都为空」时才提示。
  - `handleTalk` 在确认 targetNpc 后统一 `advance('对话')` + `advance('对话'+名称)`。
  - 「对话」列表现在同时列出 NPC / 召唤物 / 怪物（怪物按名称去重、只列存活），解决"看不到能对话史莱姆"的可发现性问题。
  - 怪物解析复用已加载的 `mapMonsters`（优先存活个体），避免重复查库。
- `server/src/modules/command/handlers/game-command.handler.ts`
  - '对话' case 移除重复 advance；露娜兑换判定收紧为 `/露娜.*未知/`，
    普通「对话 露娜」改回走 `handleTalk`（原版 L1410 按六字命令"对话露娜未知"判断，且兑换分支不推进"对话"成就）。

### 其它 NPC 是否受影响
统一在 `handleTalk` 内推进后，所有对话对象（NPC / 召唤物 / 怪物 / 特殊剧情NPC）都会推进
`对话` 与 `对话+X`，所以「对话白3」「对话3」等同类要求一并修好，不是逐个 NPC 的问题。

## 20:36 战斗日志诊断：玩家死后怪物与召唤物无限互殴、反复卷土重来

### 现象
森林深处，玩家（伊卡洛斯）倒下后，斑点牛/绿毛龟/精英绿毛龟仍每 4 秒一轮持续攻击召唤物
「花园宝宝」「白」，两只召唤物每轮都被打进「卷土重来(30秒)」，并继续反击，循环不终止。

### 结论：不是原版行为，是复刻偏离（3 处叠加）
1. **召唤物也被赋予「卷土重来」**（主因）
   - 原版 `战斗相关.ecode L3674` 有门槛 `.如果真 (防御方.特殊序号 > 0) ' 死掉的是玩家`，
     卷土重来**只对玩家**；宠物（特殊序号 < -1 / 0）被打到 HP≤0 就是真死。

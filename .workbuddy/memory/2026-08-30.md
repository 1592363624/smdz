## 文档：README 补充 GitHub Actions Secrets 说明

在 `README.md` 的「部署到 Windows 服务器」章节下新增「GitHub Actions Secrets 配置」小节，
用表格标注 6 个仓库 Secret 与项目文件的对应关系：

- `ENV_FILE` → `server/.env` 的完整内容（部署时经 `.env.upload` 覆盖写入服务器 `server/.env`）
- `WIN_APP_NAME` → `deploy/windows/deploy.ps1` 的 `-AppName`，即 PM2 进程名（如 `smdz-server`）
- `WIN_HOST` / `WIN_USER` / `WIN_SSH_KEY` → SSH 连接三件套，用于 `.github/workflows/deploy.yml`
- `WIN_PATH` → 服务器部署根目录，支持 `/c/wwwroot/smdz`、`C:/wwwroot/smdz`、`C:\wwwroot\smdz` 三种写法

关键约束：`WIN_HOST`/`WIN_USER`/`WIN_APP_NAME`/`ENV_FILE` 缺失时 deploy.yml 的 `require_value` 会直接报错退出。
